# Litra Glow render

`front.png` is the official transparent Logitech Litra Glow product render
used by the Logitech Creators product page. It is bundled only as a product
identification asset for the Litra Glow device view.

Source: <https://resource.logitech.com/w_1206%2Cc_limit%2Cq_auto%2Cf_auto%2Cdpr_1.0/d_transparent.gif/content/dam/logitech/en/creators/products/products-litra-glow-hero.png?v=1>
